Postcat is an API client inside Chrome DevTools. Capture a network request from the page you're debugging, edit it and send it again. You can also import requests already recorded by DevTools.

Compare the replay with the original response to see what changed. Inspect the response in the panel or save it to a file. Keep requests you want to reuse in a local collection.

To get started, open DevTools on a page and select the Postcat tab. Look in the DevTools overflow menu if the tab is hidden. Click Start recording and allow capture to begin.

Captured traffic is processed locally. Postcat has no backend or telemetry. Your passphrase protects saved requests in an encrypted collection in your browser. When you replay a request, Postcat sends the data in the editor to the server you choose and follows redirects. Replays use only cookies included in the editor. HTML preview can load resources referenced by the response. See the privacy policy for details.
