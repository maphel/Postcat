Postcat is a user-directed API debugging client inside DevTools. Recording and log import require the user to read an in-panel disclosure and choose Allow capture. Postcat reads the inspected tab's request URLs, headers and request/response bodies. Arbitrary payloads may contain personal or authentication data. Captured traffic and filter text stay in panel memory. Saved requests are encrypted before writing to chrome.storage.local, using AES-256-GCM with a key derived from the user's passphrase. Setup migrates existing collections. Postcat stores neither the passphrase nor the key. There is no telemetry, analytics or developer-operated backend. Send transmits the edited request to the user-selected HTTP or HTTPS endpoint and follows redirects. Optional sandboxed HTML Preview blocks scripts but may load resources referenced by the response. All application JavaScript is bundled in the package.

To test, open https://example.com/ in Chrome and select Postcat in DevTools. Look in the DevTools overflow menu if the tab is hidden. Click Start recording and choose Allow capture. Open Postcat Options and turn off XHR / Fetch only to include all request types. Hard reload the page (Ctrl+Shift+R or Command+Shift+R), select the captured GET request and choose Send. Click Save to collection and choose and confirm a passphrase of at least 16 characters. Lock the collection in the Saved tab and unlock it with the same passphrase. No Postcat account or developer-hosted service is required.
