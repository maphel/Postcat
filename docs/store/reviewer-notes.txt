Postcat is a user-directed API debugging client inside DevTools. It reads the inspected tab's request URLs, headers and request/response bodies for capture, editing and replay. Payloads are arbitrary and may contain personal or authentication data; Postcat does not classify or redact them. Captured traffic is held locally, and saved requests use chrome.storage.local. There is no telemetry, analytics or developer-operated backend. Send transmits the edited request to the user-selected endpoint and follows redirects. Optional sandboxed HTML Preview blocks scripts but may load resources referenced by the response. All application JavaScript is bundled in the package.

To test: open DevTools on an ordinary web page, open the Postcat tab (possibly in the DevTools overflow menu), reload the inspected page to capture traffic, select a request, edit it if needed and choose Send. No Postcat account or developer-hosted service is required. You can also create a request with the + button or paste a cURL command.
