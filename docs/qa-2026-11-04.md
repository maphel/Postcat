# Quality audit — 2026-11-04

Tracking: [issue #26](https://github.com/maphel/Postcat/issues/26).

The audit reviewed all application modules and exercised normal, empty, invalid, failed,
cancelled and boundary states through pure helpers, the panel DOM and the real extension worker.
Fixes stay in the existing modules. Capture trimming, layout limits and JSON validation each
have a shared source of truth; no runtime dependency, saved-data format or permission changed.

## Repaired defects

- Cross-panel cancellation token collisions and delayed cancellation of queued requests.
- Non-UTF-8 encoding of URL Basic-auth credentials.
- UTF-16 big-endian response decoding.
- cURL caret corruption, dropped empty headers, query data after fragments, swallowed URLs
  after `--ca-native`, unterminated ANSI quotes, unsafe custom-method quoting and panel rejection
  of cURL executable paths.
- Stale text available through Copy after switching to an already-sent binary preview.
- Unicode search offsets outside the original DOM text.
- Media durations displaying `0:60` and already formatted JSON reported as invalid.
- Failed storage reads blocking boot, unread-data preservation, false save-success notices
  after failed writes, and out-of-range persisted pane dimensions.
- Captured-list overflow through duplicate and undo.
- Release tagging accepting a different version's title by prefix.

Bug regressions were observed failing before their fixes. Independent agents reviewed the fixes;
review also caught an ANSI-escape regression, which was corrected and tested. Slower diagnostic
runs exposed test races around list rendering and pending fixture writes; those tests now poll
the expected state or isolate their storage writes.

## Limits of the result

The percentages above measure execution coverage of `src/lib`, not product reliability.
They do not establish a 95–99% probability that arbitrary use is correct, or prove every possible
input/state combination. Browser suites cover the listed scenarios on the stated Chromium
version; Chrome 116, other Chromium variants, OS-specific layouts and arbitrary servers/codecs
were not all exercised. Real DevTools uses a local HTTP site, not production accounts.

Documented platform limits remain: unavailable DevTools blob/stream bodies, text-recorded file
uploads, hidden replay `Set-Cookie` headers and finite body limits. No release, merge, permission
expansion, storage migration or dependency upgrade was performed.
